7. VERIFICACIÓN DE SINTAXIS Y PUERTOS
------------------------------------------------------------
Comando:  sudo apache2ctl configtest
Salida:
Syntax OK

Comando:  sudo ss -tlnp | grep apache2
Salida:
LISTEN 0      511                 *:443             *:*    users:(("apache2",pid=1711,fd=6),("apache2",pid=1710,fd=6),("apache2",pid=1707,fd=6))
LISTEN 0      511                 *:80              *:*    users:(("apache2",pid=1711,fd=4),("apache2",pid=1710,fd=4),("apache2",pid=1707,fd=4))

Observaciones:
Apache escucha en los puertos 80 y 443. El puerto 443 se debe a que el módulo
ssl está habilitado (Listen 443 en ports.conf). El proyecto prevé HTTPS en el
puerto 8900, que se configurará en la Fase 4.

10. CONCLUSIÓN
------------------------------------------------------------
En esta fase se completó con éxito la puesta en marcha del servidor web base Apache2 
en el entorno local sobre WSL2. Se confirmó que el servicio cuenta con arranque automático y 
se encuentra activo y respondiendo peticiones HTTP en el puerto 80 con código 200 OK.

dato relevante para la posterior configuración del puerto HTTPS (8900). De este modo, la base del servidor queda lista y 
verificada para la configuración del Virtual Host, el Reverse Proxy y la capa SSL en las siguientes fases.
